## 📖 About
A zen-inspired productivity tool using AI to prioritize tasks based on user energy levels and workflow patterns. Designed to help you achieve deep focus and maximum output.

## ✨ Features
- 🧘 **Zen Interface** — Calm, distraction-free design
- 🤖 **AI Prioritization** — Energy-based task sorting
- ⏱️ **Deep Work Mode** — Focus timer built in
- 📊 **Progress Tracking** — Visual productivity reports
